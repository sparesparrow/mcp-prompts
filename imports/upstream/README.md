# Originální podklady — první dávka

Tato dávka kopíruje beze změny pět podkladů ze tří repozitářů. Manifest uvádí původní cestu a Git blob SHA; hash byl ověřen proti obsahu z GitHubu včetně koncových řádků. Přiložené LICENSE zachovávají původní autory. Nejde o úplný import všech nalezených promptů.

Soubory jsou mimo data/prompts, proto je běžný loader s výchozí cestou nenačítá. Nenastavuj PROMPTS_DIR na tento adresář. Žádné nástroje, agenti, hooky ani konfigurace se tímto importem nezapínají. Originály nejsou bezpečnostní pravidla pro tento repozitář.

Původní MIA persony obsahují smyšlené metriky, tvrzení o již provedené práci a pokyny jednat bez souhlasu. Jsou zachované pro srovnání, nikoliv schválené k automatickému použití. Analytický JSON používá podmínky Handlebars a resource URI; před aktivací vyžaduje převod nebo odpovídající podporu klienta.

hard-coder/prompts.yaml a pravidla cursor-rules mají v kořeni zdrojových repozitářů GPLv3. V této dávce nejsou kopírovány ani přelicencovány na MIT; manifest je eviduje pro samostatné převzetí se zachovanými podmínkami. Další JSON prompty a skills zůstávají mimo tuto první dávku.
